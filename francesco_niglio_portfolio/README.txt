- assets/site.js: menu mobile e anno automatico

PRIMA DI PUBBLICARE
1. Sostituisci i riquadri "INSERIRE..." con fotogrammi e immagini autorizzati.
2. Aggiorna i testi delle schede film con anno, durata, crediti e link corretti.
3. In contatti.html sostituisci INSERIRE-EMAIL e INSERIRE EMAIL con il tuo indirizzo.
4. Inserisci i tuoi link Vimeo, Instagram e LinkedIn.
5. Verifica la biografia e tutti i crediti. I testi attuali sono una bozza editoriale, non una biografia definitiva.
6. Valuta se mantenere Ammaculat nella sezione progetti: è documentario e potrebbe avere una pagina o una categoria separata.

PUBBLICAZIONE GRATUITA CON GITHUB PAGES
1. Crea un account gratuito su https://github.com/
2. Crea un nuovo repository pubblico chiamato: francesco-niglio.github.io
   (puoi scegliere un nome diverso, ma questo formato rende semplice l'indirizzo).
3. Carica tutti i file e le cartelle contenuti in questo archivio nella cartella principale del repository.
4. Apri Settings > Pages.
5. In "Build and deployment", scegli "Deploy from a branch", branch "main", folder "/ (root)", poi Save.
6. Dopo la pubblicazione il sito sarà raggiungibile all'indirizzo:
   https://TUONOMEUTENTE.github.io/

NOTA
Il sito usa Google Fonts tramite CDN: per questo aspetto tipografico è necessaria una connessione internet. Se vuoi eliminare anche questa dipendenza, si può passare a font di sistema.
Nessun dominio personalizzato è incluso: quello richiederebbe l'acquisto del dominio.
